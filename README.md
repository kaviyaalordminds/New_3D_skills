# Forge3D — Landing Page

Marketing landing page for Forge3D, an AI-assisted 3D asset creation tool
for creators and game developers. Built with Next.js (App Router),
TypeScript, and Tailwind CSS v4.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Structure

- `src/app` — root layout, global styles, and the page entry point
- `src/components` — page sections: `Navbar`, `Hero`, `Features`,
  `HowItWorks`, `Pricing`, `CTA`, `Footer`
- `.claude/skills` — the `ui-ux-pro-max` Claude Code skill suite used to
  drive style, color, and typography decisions for this page

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run lint` — run ESLint
